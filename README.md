# Rishabh Sharma — Portfolio

Personal portfolio site, built with plain HTML/CSS/JS and hosted on Netlify.

Live at: https://itisrishabhsharma.netlify.app/

## Filling in content

Search the codebase for `[PLACEHOLDER` and `[NAME` to find every spot that still
needs real content — currently just testimonial quotes and optional project
screenshots. See `index.html` for the full list.

Images referenced under `images/` are placeholders — drop real files in with the
same names, or update the `src` attributes in `index.html`.

## Local preview

Just open `index.html` in a browser, or run a local static server:

```
npx serve .
```
